# Simulink 闭环调参流程

## 必须执行的闭环

当 Simulink 可用时，不要凭经验猜参数，按以下流程执行：

1. 读取模型名、变量、Mask 参数、工作区参数和输出信号名。
2. 根据模型使用 base workspace、model workspace 或 data dictionary 写入初始试探参数。
3. 运行模型。
4. 提取 `Vo`、`iL`、谐振电流、占空比或频率指令、误差信号和限幅标志。
5. 计算指标。
6. 诊断波形。
7. 每次只更新一类参数。
8. 保存或汇总每轮记录，避免重复试错没有轨迹。

## 物理电路模型优先

当任务涉及 DC/DC 电力电子变换器的 Simulink 仿真，尤其用户要求“电路”“物理模型”“电力电子器件”“真实 Buck/Boost 模型”或要交付 `.slx` 时，优先使用物理电路模型进行验证：

- 功率级应由电源、MOSFET/IGBT/理想开关、二极管或同步整流器、电感、电容、负载、测量模块、门极/PWM 驱动、`powergui` 或 Simscape Solver 等物理/电力电子块连接而成。
- 控制器可以是 Simulink 控制块、离散 PI、Stateflow 或 MATLAB Function，但不能用 MATLAB Function、传递函数或状态方程直接替代最终功率级电路。
- 平均模型、传递函数模型或函数功率级只用于快速初筛、理解趋势或缩小 PI 搜索范围；报告中的最终候选参数必须在物理电路模型或明确的开关级器件模型上复核。
- 交付新模型时，必须保存 `.slx`，并至少运行一次编译/仿真验证，确认测量信号、控制输入、求解器、采样时间和输出记录可用。
- 如果由于工具箱缺失、求解器失败或模型过慢而无法做物理电路仿真，要明确说明真实原因，并把平均模型结果标注为“初筛结果”，不能称为最终验证。

## 优先观察的信号

- 输出电压 `Vo`
- Buck/Boost 的电感电流 `iL`
- LLC 的谐振电流
- 占空比指令 `d` 或开关频率指令 `fs_cmd`
- 电流参考 `iL_ref`
- 电压误差和电流误差
- PI 输出限幅前、限幅后信号
- 如果模型提供，观察限幅或抗积分饱和状态

## 指标

| 指标 | 含义 |
| --- | --- |
| `overshoot` | 输出峰值相对目标值或稳态值的超调 |
| `settling_time` | 进入并保持在指定误差带内所需时间 |
| `steady_error` | 最终值与目标值的偏差 |
| `tail_std` | 稳态尾段标准差，用作持续振荡判断 |
| `saturation_ratio` | 占空比或频率指令触碰限幅的时间比例 |
| `current_ripple` | 电感电流或谐振电流纹波 |
| `current_peak` | 电感、开关管、二极管、变压器等器件应力检查 |

## 参数更新逻辑

| 结果 | 下一步 |
| --- | --- |
| 输出发散 | 停止增益加大；检查控制方向、反馈接线、限幅、求解器和单位 |
| 高频振荡 | 降低内环 `Kp`；检查采样时间和滤波 |
| 低频振荡 | 降低外环 `Ki` 或 `Kp`；放慢外环 |
| 稳定但太慢 | 小步增大当前正在调的环路 `Kp`；若仍有稳态误差，再增大 `Ki` |
| 波形平滑但稳态误差大 | 增大对应 `Ki`；同时检查是否被限幅 |
| 超调大 | 降低外环增益；加入软启动或参考斜坡 |
| 长时间触碰限幅 | 检查目标不可达、功率级设计不足、积分饱和或控制方向错误 |
| 电压好但电流过大 | 判为不安全结果；降低激进程度或重新设计功率级 |

## MATLAB/Simulink 实操注意

- 优先沿用项目里已有脚本和变量名。
- 根据模型实际结构使用 `logsout`、`out`、`Simulink.SimulationOutput` 或 `To Workspace` 输出。
- 对开关级模型，求解器步长要能分辨开关波形。可从 `Tswitch/100` 到 `Tswitch/200` 附近开始。
- 如果开关/物理电路模型太慢，可先用平均模型探索控制器，再用物理电路或开关级器件模型确认候选参数。
- 如果模型运行失败，要引用真实错误，并提出下一步可执行修复。

## 面向用户的汇报模板

```text
我运行/尝试了第 N 轮，参数为 ...
观察到：...
指标：...
诊断：...
下一轮：将 ... 改为 ...，原因是 ...
验证状态：...
```

除非仿真确实运行过，或用户提供了仿真数据，否则不要写“仿真表明”。
