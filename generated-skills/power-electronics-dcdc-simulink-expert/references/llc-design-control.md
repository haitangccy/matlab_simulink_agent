# LLC 设计与控制

## 谐振腔

LLC 包含 `Lr`、`Cr`、`Lm`、变压器匝比、副边整流和输出电容。`Lr` 与 `Cr` 决定主谐振频率；`Lm` 会影响增益曲线、励磁电流、轻载损耗和 ZVS 裕量。

```text
fr = 1 / (2*pi*sqrt(Lr*Cr))
fm = 1 / (2*pi*sqrt((Lr + Lm)*Cr))
```

通常 `fm < fr`。额定点常设计在 `fr` 附近，但实际工作点要由输入范围、所需增益、ZVS 裕量和器件应力共同决定。

## 初步设计流程

1. 明确输入范围、输出电压、输出功率、桥式结构、整流方式、目标频率和效率。
2. 估算变压器匝比。半桥可先粗略用 `n ~= Vin_nom/(2*Vo)`，全桥可先粗略用 `n ~= Vin_nom/Vo`。必须再按模型里的增益定义确认。
3. 计算直流负载 `Ro = Vo^2 / Po`。
4. 按整流方式和分析约定换算交流等效负载。
5. 选择品质因数 `Q` 和谐振阻抗 `Zr`。
6. 根据 `fr` 和 `Zr` 计算初始 `Lr`、`Cr`。
7. 选择 `Lm/Lr`，常见初值可从 3 到 8 附近试探，但这不是固定答案。
8. 检查低输入满载增益、高输入轻载输出、电流应力、频率范围和 ZVS。

## 参数影响

| 参数 | 过小的影响 | 过大的影响 |
| --- | --- | --- |
| `Lr` | 谐振电流大，开关管应力高 | 功率传输能力弱，低输入满载可能带不起 |
| `Cr` | 谐振阻抗高，电容电压应力可能偏大 | 谐振电流偏大，环流和损耗增加 |
| `Lm` | 励磁电流大，ZVS 容易但轻载损耗高 | 励磁电流小，ZVS 变难，增益范围变窄 |

## 调频控制方向

多数 LLC 是调频控制，不是普通占空比控制。

常见工作区间内的方向：

```text
Vo < Vref -> 需要提高增益 -> 降低 fs
Vo > Vref -> 需要降低增益 -> 提高 fs
```

如果方向接反，环路可能顶到频率限幅或持续振荡，单纯改 PI 增益也救不回来。必须检查模型中的真实增益曲线和控制实现。

## 控制护栏

- 设置 `fs_min` 和 `fs_max`。
- 加入频率变化率限制。
- 采用高频软启动，再逐步降到工作频率范围。
- 启动和模式切换时，对 PI 积分项进行限幅、清零或跟踪。
- ZVS/ZCS 和器件应力必须用开关模型验证。
- 不只看输出电压，还要看谐振电流和开关节点波形。
