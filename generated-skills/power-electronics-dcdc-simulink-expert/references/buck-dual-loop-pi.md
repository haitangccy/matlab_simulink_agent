# Buck 双闭环 PI 调参

## 控制结构

典型结构：

```text
Vref -> 电压外环 PI -> iL_ref -> 电流内环 PI -> 占空比指令 -> Buck 功率级 -> Vo
                                             ^                              |
                                             |                              |
                                            iL -----------------------------
```

电流内环必须比电压外环快。不要同时调两个环。

## Buck 物理电路验证要求

Buck PI 调参的最终验证应优先在物理电路模型或开关级器件模型中完成。典型物理模型至少包含：

- DC 输入电源；
- 高边 MOSFET/IGBT/Ideal Switch 及 PWM 门极；
- 续流二极管或同步整流器；
- 电感、电容、ESR 与负载；
- 输出电压测量、电感电流测量、占空比/门极信号记录；
- `powergui` 或 Simscape Solver Configuration/Electrical Reference。

平均 Buck 模型可用于快速搜索 PI 的大致范围，但不能单独作为“最终 PI 参数”依据。每一组候选参数至少要回到物理电路模型上检查启动、稳态、负载阶跃、电感电流峰值、纹波和占空比限幅。

## 强制调参顺序

1. 断开或冻结电压外环。
2. 给定固定或阶跃的 `iL_ref`。
3. 令 `Ki_i = 0`，从较小 `Kp_i` 开始逐步增大，直到 `iL` 跟踪速度可以接受。
4. 如果出现高频噪声或占空比毛刺，先减小 `Kp_i`，再检查采样时间、PWM 延迟和电流滤波。
5. 逐步加入 `Ki_i`，减小电流稳态误差。
6. 在电流参考阶跃和负载变化下验证内环。
7. 固定内环参数。
8. 接入电压外环，令 `Ki_v = 0`，保守增大 `Kp_v`。
9. 逐步加入 `Ki_v`，消除电压稳态误差。
10. 验证启动、负载阶跃、输入电压阶跃、限幅恢复和抗积分饱和。

若使用物理开关模型调参，建议先用较小候选集扫描，确认波形稳定和仿真速度，再围绕较优点局部细化。不要为了加快速度把最终功率级替换成 MATLAB Function 或纯状态方程后直接下结论。

## 波形诊断表

| 波形现象 | 优先怀疑 | 下一步 |
| --- | --- | --- |
| `iL` 跟踪慢 | `Kp_i` 偏小 | 小步增大 `Kp_i` |
| `iL` 高频抖动 | `Kp_i` 偏大、采样太慢或滤波问题 | 减小 `Kp_i`；检查采样时间和电流滤波 |
| 电流存在稳态误差 | `Ki_i` 偏小 | 逐步增大 `Ki_i` |
| 电流低频摆动 | `Ki_i` 偏大或积分饱和 | 减小 `Ki_i`；加入或检查抗积分饱和 |
| `Vo` 上升慢但稳定 | 外环太温和 | 先增大 `Kp_v`，再增大 `Ki_v` |
| `Vo` 超调大 | 外环太激进 | 减小 `Kp_v` 或 `Ki_v`；放慢启动或参考斜坡 |
| 占空比长期限幅 | 参考不可达、积分饱和或功率级能力不足 | 检查占空比限幅、输入、负载、软启动和积分限幅 |
| 外环接入后内环失稳 | 电压环带宽过高 | 放慢电压环；重新检查内环裕量 |

## 单轮调参汇报格式

```text
第 N 轮
参数：Kp_i=...，Ki_i=...，Kp_v=...，Ki_v=...
测试：启动/负载阶跃/输入阶跃...
指标：overshoot=...，settling=...，steady_error=...，duty_sat=...
诊断：...
下一步修改：...
状态：初始试探值/当前轮参数/候选参数/在该模型下已验证
```

验证工况和模型范围没有说清楚前，不要把某组参数称为最终参数。
