# 2026-05-09 工作记录

## 48V→12V 同步 Buck 变换器双闭环设计与调参

完成了完整的 48V→12V/500W 同步 Buck 变换器设计，包括：

### 设计参数
- 拓扑：同步 Buck（MOSFET 主开关 + MOSFET 同步整流管）
- 电感：15 µH / 10 mΩ DCR
- 电容：220 µF / 5 mΩ ESR
- 开关频率：100 kHz
- 电流内环：Kp=0.0196, Ki=13.1, 带宽 10 kHz
- 电压外环：Kp=0.595, Ki=9390, 带宽 1.5 kHz
- 内外环带宽比：6.7（满足 5~10 倍准则）

### 生成的文件
1. `buck_48v_12v_init.m` — 参数初始化脚本
2. `build_buck_model.m` — Simulink 模型自动构建脚本（Simscape Electrical）
3. `tuning_helper.m` — 调参辅助与仿真验证脚本
4. `48V_12V_Buck_设计与调参报告.md` — 完整设计报告

### 设计方法
- PI 整定采用零极点对消 + 带宽配置法
- 参考了 power-electronics-dcdc-expert 知识库中的 PI 调参手册
- 仿真模型基于 Simscape Electrical 搭建，使用 ode23tb 求解器，步长 100ns
